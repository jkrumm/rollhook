## Finding (rollhook-side, not basalt)

First load after login logs one `401` on `/jobs?limit=200` (header is `Bearer ` with an empty token), the list shows "Failed to load jobs" for a few seconds, then polling succeeds. Cause: `App.tsx` calls `configureApi(token)` in a parent `useEffect`, which runs after the child's first fetch. `App.tsx` and `api/client.ts` are untouched by this migration, so it predates it. Not fixed here (outside the ask).
